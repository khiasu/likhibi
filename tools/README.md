# LIKHIBI — Utility Tools & Scripts

This directory contains standalone utility scripts supporting data handling, format conversion, and testing.

## Directory Structure

```
tools/
├── README.md                      # Utility scripts guide
└── legacy/                        # Legacy prototype scripts archived for reference
    ├── generate_dict.ps1          # Early script that parsed corpora into Kotlin maps
    ├── list-models.js             # Early Gemini API model listing script
    └── test-api.js                # Early Gemini API test script
```

> **Warning**: Scripts in `legacy/` are archived from the initial keyboard prototype and are kept for historical context. Active development must use the modular Python scripts under `nlp_research/`.
