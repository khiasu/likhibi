## 2. Decoupling Core Principles

1. **Research First**: Model training, corpus preprocessing, dataset curation, and translation prototyping reside strictly in `nlp_research/`.
2. **Mobile as Platform Demo**: The Android keyboard application (`app/`) acts strictly as a mobile host interface for displaying predictions and translations generated by the research models.
3. **Clean Abstractions**: The Android IME logic interacts ONLY through defined interfaces (`PredictionEngine`, `TranslationEngine`, `LexicalRepository`), preventing direct coupling to specific hardcoded implementations.
